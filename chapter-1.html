1.1 Architectural Theory and IT/OT Convergence

Modern industrial enterprises face a massive challenge: bridging legacy operational networks with scalable cloud analytics platforms. This process, known as IT/OT convergence, introduces severe security risks to once-isolated production floors.

Historically, plant floor operations relied on physical isolation (air-gapping) to preserve the safety of human operators and equipment. However, modern businesses require real-time telemetry, predictive machine maintenance, and centralized oversight. This demands high-performance pipelines that can extract data from low-level controllers up to cloud data lakes without exposing physical assets to the public internet.

This manual outlines the exact steps to build a high-availability infrastructure bridge. It details the process from bare-metal media creation to cloud-managed industrial networks. By following this guide, you ensure that every virtualization layer, storage datastore, and management endpoint matches enterprise-grade security postures.

1.2 Defining the Network Scope Parameters & Assets

To guarantee strict traffic isolation post-migration, the system utilizes two non-overlapping routing planes. The Industrial Control Systems (ICS) layer utilizes an expanded Class B subnet profile to coordinate physical and virtual industrial assets across the facility:

  • Management/Security Plane Core Scope: 10.0.0.0/24 (Subnet Mask: 255.255.255.0)
  • Industrial Control Systems (ICS) Operational Subnet: 192.168.0.0/16 (Subnet Mask: 255.255.0.0)
