# The Hybrid Automation Blueprint

Static site for SOP-INF-AZM-01 (v5.0). Open `index.html` to read it locally.

## Publish with GitHub Pages
1. In VS Code: Source Control → Initialize Repository → commit → Publish to GitHub.
2. On GitHub: Settings → Pages → Deploy from a branch → `main` / root → Save.
3. The site appears at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

Note: the document is marked CONFIDENTIAL. A public repo/Pages site is public. Pages are set to `noindex`, which only discourages search engines.
