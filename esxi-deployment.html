ESXi Host Deployment Guide

Author: Infrastructure Engineering Team · Classification: CONFIDENTIAL – System infrastructure documentation

Target management IP: 10.0.0.150 · Primary storage target: OTCYBERDATAStorage

1. Executive Summary

This technical document outlines the standardized workflow for deploying a bare-metal VMware ESXi hypervisor architecture within a hybrid local network environment. The target configuration transitions from bare-metal media flashing to localized routing provisioning via a physical laptop intermediary, culminating in static management allocation and centralized storage integration.

2. Installation Media Preparation

Prior to hardware provisioning, standard bootable system installation artifacts must be acquired and formatted safely:

  • ISO Acquisition: Download the targeted enterprise VMware ESXi installation binary image directly from the authorized Broadcom Support Portal.
  • Media Burn Specification: Insert an empty USB storage unit. Use the open-source tool Rufus to format the drive. Select the downloaded ESXi ISO file, choose either MBR or GPT depending on your target board architecture, and write the image in ISO mode.

3. Dedicated Laptop Network Intermediary

To guarantee stable IP addressing during the baseline network deployment phase, an isolated staging environment is leveraged:

  • Dell Physical Hardware: A physical Dell laptop is configured explicitly to serve as a temporary network coordination bridge.
  • DHCP Scope Integration: Configure a localized DHCP service wrapper bound to the network interface card on the Dell laptop. This interfaces directly with the primary Home Router to orchestrate local lease bounds safely and provide dynamic address resolution prior to static structural mapping.

4. Host Provisioning & Hypervisor Configuration

Once media is flashed and network provisioning handles dynamic mapping, execute hypervisor installation directly onto target hardware architecture:

5. OTCYBERDATAStorage Mount & VM Loading

Post-installation tasks mandate routing configuration optimization to expose underlying storage layer arrays safely to the hypervisor kernel:

  1. Log directly into the VMware Host Client dashboard console via https://10.0.0.150 using administrative root user credentials.
  2. Navigate to the Storage option tree in the sidebar configuration panel.
  3. Select "New Datastore" and map the system pool to the OTCYBERDATAStorage storage array layer partition infrastructure.
  4. Confirm the underlying connection statuses show green/active, allowing system administrators to instantly load, build, and deploy new operational production Virtual Machines (VMs).
