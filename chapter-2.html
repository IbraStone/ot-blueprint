2.1 High-Integrity Bootable Media Lifecycle

This procedure replaces vulnerable public imaging pipelines with an isolated, verified physical media formatting workflow.

Step 2.1.1ISO Binary Acquisition and Hash Verification

  1. Access an administrative engineering workstation equipped with unhindered, out-of-band internet access.
  2. Authenticate to the official Broadcom Support Portal utilizing your enterprise corporate infrastructure credentials.
  3. Locate the targeted enterprise VMware ESXi installation binary image matching the baseline environment hardware compatibility list (HCL).
  4. Initiate download of the raw .iso image.
  5. Once downloading concludes, execute a localized cryptographic verification via PowerShell to cross-reference the SHA-256 fingerprint against Broadcom’s published standard:
    Get-FileHash .\VMware-VMvisor-Installer-XXXX.iso -Algorithm SHA256
  6. If the resulting string does not match the vendor-supplied signature, permanently purge the file from disk and repeat the initialization pipeline.

Step 2.1.2Media Burn & Flashing Operations via Rufus

  1. Identify a dedicated, structurally clean USB storage device with a minimum capacity of 16 GB.
  2. Insert the USB storage unit into the staging terminal.
  3. Fire up the open-source block-imaging utility Rufus using elevated local administrator rights.
  4. Within the user interface, configure the target parameters exactly as specified below:
    • Device: Select the identified USB storage unit target.
    • Boot Selection: Click Select and point the application filesystem directly to the validated VMware ESXi ISO file.
    • Partition Scheme: Toggle between MBR (Legacy BIOS) or GPT (UEFI Unified Extensible Firmware Interface) based strictly on the motherboard firmware configuration of the destination server hardware.
    • File System: Allow the application to default to Large FAT32.
  5. Click START. When the application presents the option block, choose Write in ISO Image mode.
  6. Acknowledge the data destruction warning prompt. Wait for the green execution progress bar to fill completely, then click Close and issue an OS-level software extraction command to safely unmount the USB physical media.

2.2 Temporary Intermediary Network Coordination

To prevent unauthorized address space leaks and ensure zero conflict within local routing domains during installation, a physical device acts as a temporary coordination platform.

Step 2.2.1Intermediary Node Hardware Isolation

  1. Deploy a physical Dell laptop destined strictly to serve as a secure temporary network bridge.
  2. Terminate all wireless networking capability (Wi-Fi) using physical toggles or hardware OS disables to eliminate dual-homing vectors.
  3. Connect the built-in Ethernet network interface card (NIC-A) directly to an open switch port tied to the primary Home Router to validate outward path routing capability.

Step 2.2.2Tailoring the Localized DHCP Service Scope Wrapper

  1. Connect an external USB-to-Ethernet adapter (NIC-B) to the Dell laptop to act as the downstream staging interface.
  2. Launch your localized network services configuration suite or Windows Server DHCP Role management panel.
  3. Bind the active DHCP service wrapper specifically to the interface profile mapping to NIC-B.
  4. Define the localized lease scope parameters:
    • Network Scope Range: 10.0.0.100 through 10.0.0.140
    • Subnet Mask: 255.255.255.0
    • Default Gateway Assignment: The localized address of NIC-B (10.0.0.1)
  5. Initialize the service daemon. Connect a physical Category 6 patch cable from NIC-B directly into the primary onboard management interface (vmnic0) of the target bare-metal server machine.

2.3 Bare-Metal Provisioning & Hypervisor Parameter Locking

This section covers hardware initialization, interactive installation execution, and hardcoding runtime network parameters.

Step 2.3.1Target Host Hardware Initialization

  1. Insert the prepared USB installation media directly into an external USB port of the bare-metal destination server.
  2. Apply system power and enter the server's Motherboard Utility via keys such as F2, F11, or F12 depending on server design.
  3. Ensure the security settings enforce the selected boot scheme (UEFI or Legacy) matching your media creation parameters. Force the primary boot choice ranking to favor the USB device, then execute a warm system restart.

Step 2.3.2Interactive ESXi Installation Execution

  1. Allow the system to load the enterprise kernel runtime blocks into transient memory.
  2. At the welcome initialization prompt, strike the Enter key to progress.
  3. Read the End User License Agreement (EULA). Strike F11 to commit acceptance of terms.
  4. The storage installer wizard will query for available runtime paths. Select the internal local disk storage target designated to host the system hypervisor core files.
  5. Select your targeted physical language configuration map (Default: US English).
  6. Establish the global administrative password for the core root identity token. Ensure it satisfies enterprise complexity policies. Strike Enter to proceed.
  7. Finalize structural confirmation by striking F11 to execute the system layout format. Once processing terminates, pull the physical USB flash drive from the host interface and strike Enter to initialize a clean system restart.

Step 2.3.3Hardcoding Static Management Properties

  1. Once the system finishes booting to the Direct Console User Interface (DCUI) splash view, strike the F2 functional key.
  2. Authenticate using the root administrative credentials configured during installation.
  3. Navigate down to Configure Management Network and strike Enter.
  4. Select Network Adapters and verify that physical port vmnic0 is actively checked and designated as the primary Management Bridge.
  5. Navigate down to IPv4 Configuration and press Enter. Select the option for Set static IPv4 address and network configuration.
  6. Implement the exact network metrics by inputting the corresponding values below:
    Configuration parameterTarget value
    Static IPv4 Address10.0.0.150
    Subnet Mask255.255.255.0
    Default Gateway10.0.0.1
  7. Strike Enter to lock in the parameters. Select DNS Configuration, then enter your authoritative upstream local nameserver parameters.
  8. Strike ESC to back out. The DCUI screen will prompt you to apply structural updates and restart management networking loops. Strike Y to commit.
  9. Disconnect the physical network cable anchoring the target host to the intermediary Dell laptop. Safely patch the host interface back into the permanent local core network infrastructure.
